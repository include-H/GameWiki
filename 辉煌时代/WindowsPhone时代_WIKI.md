## 1. 时代概览

Windows Phone 时代指的是微软从 1996 年的 Windows CE 起步，到 2019 年 12 月终止 Windows 10 Mobile 支持为止，围绕「把 Windows 放进随身设备」进行的二十多年连续尝试。它以三种互不相同的形态出现：早期的 Windows CE / Pocket PC / Windows Mobile 是授权给硬件厂商的嵌入式系统，服务的是掌上电脑与商务手机；2010 年的 Windows Phone 7 是一次面向普通消费者的品牌与界面重启；2012 年以后的 Windows Phone 8、Windows Phone 8.1 与 Windows 10 Mobile 则被并入 Windows 主干，试图让手机、平板与个人电脑共享同一套应用。三种形态之间没有平滑的继承关系，内核换过、界面换过、合作厂商换过，唯一贯穿始终的是「Windows 要在口袋里有一席之地」这个目标。

这段历史的核心张力是「历史地位与市场结果的反差」。Windows Phone 与 Windows Mobile 在商业上从未进入过第一梯队，常年在个位数份额徘徊，最终退场；但它留下的设计与生态印记分布很广：Metro 与 Live Tiles 的界面语汇进入 Windows 8、Windows 10，并成为 2010 年代扁平化设计潮流中的一支；手机上第一次成体系地接上 Xbox Live 成就与 Gamerscore；诺基亚 Lumia 的聚碳酸酯一体成型与 PureView 成像方案把手机摄影推到了参数之外的技术讨论；UWP 与 Continuum 把「同一款应用跑在多种屏幕上、手机接上显示器当桌面用」的想法提前摆到了台面上。这些内容在设计史与生态史里站得住脚，在市场报表里则始终没有对应的位置。

按「为什么重要 / 留下什么经典 / 如何影响后来 / 玩家当时怎样体验」这四个问题看，Windows Phone 的案例价值集中在前两问与第四问：它为什么在平台战争里重要，是因为它把界面语言、跨设备应用与手机桌面模式这几条线索同时推到了公众面前；它留下什么，主要是设计语汇与若干产品思路；玩家当时的体验则由两套记忆组成——一类是 Windows Mobile 时代在掌上电脑上折腾软件、炒股、导航的早期用户，另一类是 2010 年代买 Lumia 拍照、又因为商店里搜不到应用而最终离开的手机用户。

本文把平台按「硬件定位 + 软件生态 + 平台气质 + 胜负原因 + 历史定位」来写，技术参数只作为解释性材料，不用来说明命运。需要说明的是，这条产品线已经终止，本文按已结束的平台史处理；与之相邻的 Surface Duo、Windows 10 on ARM 等后来项目，只在它们说明这段历史如何收尾时提及。文中把事实、推断与评价分开：可从公开资料核对的事件与规格按事实写，对因果的解释注明是解释，对产品好坏的判断交由读者自取。凡撰写环境无法复核的具体数字与日期，正文以「待核实」标记，不用估计值填补。

对中文读者而言，这段历史还有一层特别的错位感。Windows Mobile 在中国大陆曾以「多普达」的形象被商务人群记住，掌上电脑与刷机论坛构成了第一批智能手机用户的集体经历；到了 Windows Phone 时代，诺基亚的品牌好感与 Lumia 的外观让这条产品线一度被寄予厚望，但支付宝、淘宝、微信等功能的不完整让日常使用难以为继。两个阶段的中国记忆都可以看作同一件事的两面：微软能把系统做到某个细处很出色，却始终没把「日常要用的东西都在里面」这件事办成。

## 2. 时代时间线

### 2.1 前史：Windows CE 与口袋电脑（1996–2003）

微软进入随身计算的起点是 Windows CE。1996 年 11 月，Windows CE 1.0 发布，内部代号 Pegasus，配套的硬件形态被称为 Handheld PC（H/PC）：带键盘的翻盖式小机器，屏幕以灰度为主，内存以兆字节计。卡西欧 Cassiopeia、康柏、惠普、NEC、飞利浦等厂商先後推出 H/PC 产品，用途集中在记事、日程、简单表格与串口/红外同步，目标是让桌面上的 Word、Excel 文件能在口袋里打开。当时这类设备的对手是 1996 年 3 月上市的 Palm Pilot 与它的 Palm OS——不追求完整办公能力，而是用「快、省电、一按就用」把电子记事本变成了大众产品，这也定下了此后几年掌上设备路线的分野。

这一代 H/PC 的典型配置在今天看来很小：卡西欧 Cassiopeia A-10 / A-11 一类机型的屏幕为灰度液晶，内存从 2MB 到 4MB，靠电池组供电，与电脑的连接依赖串口或红外，软件要按机型与处理器架构分别下载安装。设备价格高、目标用户窄，微软把 Windows CE 定位成桌面系统的延伸，而不是独立的消费电子品类，这一定位决定了它此后很长时间的形态：先服务办公文件的随身访问，再谈娱乐与大众市场。掌上电脑与普通人的距离，要到手机形态出现之后才被拉近。

1997 年 9 月，Windows CE 2.0 带来彩色屏与更完整的 Pocket Internet Explorer，配套出现 Handheld PC Pro 与「Palm-size PC」两类形态：后者是竖屏、以触控笔操作的小型设备，直接对标 Palm。1998 年前后的 Palm-size PC 包括卡西欧 Cassiopeia E-10 / E-11、飞利浦 Nino 等，界面与 Palm 相比偏复杂，续航与易用性是其短板。到 2000 年 4 月，微软改用在 1999 年发布 Windows CE 3.0 上裁剪的 Pocket PC 2000，取消 Palm-size PC 名称，统一成「Pocket PC」。康柏 iPAQ H3600（2000 年）成为这一阶段最有代表性的机器，彩色屏、可换扩展背夹（CompactFlash、PC 卡）与丰富的第三方软件让它在爱好者手里变成可以不断加装的平台；惠普 Jornada、卡西欧 Cassiopeia、东芝、Symbol 等产品线并存，戴尔在 2002 年以 Axim 进入这一市场。

2001 年秋的 Pocket PC 2002 进一步把界面贴近桌面 Windows，把这一平台确立为「掌上电脑」而非「电话」的默认选择，尽管带电话模块的机型已经出现。这一阶段的核心结构是授权模式：微软只提供系统，硬件由厂商做，处理器有 ARM、MIPS、SH 等多个体系，移植与优化由厂商自行处理。掌上电脑的价格与目标用户都偏高，中文市场的对应记忆是商务人士手里的「PDA」，以及围绕掌上电脑建立的软件下载与讨论社区。真正把 Windows CE 从 PDA 推向手机，要等下一个阶段；而 PDA 品类本身在智能手机普及后迅速萎缩，惠普并购康柏后继续经营 iPAQ，Palm 后来也在 2006 年推出过运行 Windows Mobile 的 Treo 700w，PDA 与手机的边界由此合拢。

### 2.2 Windows Mobile 的十年与触屏转向（2003–2010）

2003 年 6 月，微软启用「Windows Mobile」品牌，把系统分成两条线：带触控笔与手写识别的 Pocket PC 版，以及不带触控、以数字键盘为主的 Smartphone 版。此后是 Windows Mobile 5.0（2005 年 5 月，代号 Magneto，加入持久化存储，断电不再丢数据，并强化了 .NET Compact Framework）、Windows Mobile 6（2007 年 2 月，代号 Crossbow，细分为 Professional / Standard / Classic）、Windows Mobile 6.1（2008 年 4 月）与 Windows Mobile 6.5（2009 年 10 月）。这几代之间的变化以功能补强为主，界面框架、输入方式与授权模式基本延续。

这一代的硬件主导者是 HTC。它以代工与自有品牌两条腿出货，在中国大陆以「多普达」品牌销售，机型覆盖从数字键盘到侧滑全键盘的多种形态，在中高端商务市场积累了稳定用户；三星、摩托罗拉（如 Q 系列）、LG、惠普、戴尔、华硕、倚天、神达等也各有产品，Palm 的 Treo 700w / 750 也曾采用这一系统。各家在同一套系统上叠加自制的今日界面与输入法，HTC 的 TouchFLO（2007 年随 Touch 系列推出）与后续的 Touch Diamond、Touch Pro、HD 系列把这种定制做到极致；索尼爱立信 Xperia X1（2008 年）与三星 Omnia 系列也各有设计。2009 年 11 月的 HTC HD2 是这条线的技术高点：4.3 英寸电容屏、1GHz 高通骁龙处理器，运行 Windows Mobile 6.5，社区后来还把它折腾成能启动 Android 与 Windows Phone 的机器。国内市场同期还有酷派等厂商在双模手机时期采用 Windows 系统（具体机型与年份待核实），多普达 818、828、S1、P800 等型号是不少商务用户的第一台「智能机」。

外部环境在这几年彻底变化。2007 年 1 月苹果公布 iPhone，同年 6 月发售；2008 年 7 月 App Store 上线。2007 年 11 月谷歌联合多家厂商成立开放手机联盟，2008 年 10 月首台 Android 手机 HTC Dream（G1）与 Android Market 面世。Windows Mobile 的授权与碎片化模式在电容触屏、应用商店与统一体验三条战线上同时吃紧：同一套系统在不同机型上的界面与性能差异很大，应用分发仍以厂商商店与第三方下载站为主，输入要靠触控笔，浏览器与多媒体体验也落后于新平台。诺基亚与它的 Symbian 在 2006 至 2010 年仍是全球与中国的智能手机主流，Windows Mobile 守住的是高价位商务细分，规模不足以支撑平台级生态。微软在 2009 年的 Windows Mobile 6.5 上补了 Windows Marketplace for Mobile 与 My Phone 云备份，属于过渡性质的补丁，市场反应平淡。

这一时期全球智能手机的主线由诺基亚的 Symbian 与黑莓（BlackBerry）占据，前者靠规模与运营商渠道覆盖大众市场，后者靠实体键盘与邮件推送服务企业客户；Windows Mobile 的处境介于两者之间，功能全但成本高、输入依赖触控笔，用户多是愿意自己调教机器的商务人士与技术爱好者。运营商在北美市场对机型的补贴与定制影响很大，Windows Mobile 机型常以运营商定制版形式出现，这既带来销量也加深了碎片化。到 2010 年前后，Symbian 与黑莓在触屏浪潮中同时失速，Windows Mobile 也没能抓住空出来的位置，机会被 Android 接走。

2010 年 4 月，微软推出面向年轻人的 Kin One 与 Kin Two（源自收购的 Danger 团队），两款机器在约两个月内停售。同年 2 月的世界移动通信大会（MWC）上，微软已经发布了与 Windows Mobile 完全切割的 Windows Phone 7，触屏转向由此完成。Windows Mobile 品牌在 2010 年前后停止更新，微软把资源集中到新平台上，早期的 OEM 与开发者则要在两套不通用的体系之间重新选择。

### 2.3 Windows Phone 7：Metro 的登场与诺基亚同盟（2010–2011）

2010 年 2 月 15 日，微软在巴塞罗那 MWC 上公布 Windows Phone 7。它的界面语言被称为 Metro（后改称 Modern UI），主张「authentically digital」，去除拟物化的光影与纹理，以字体、色块与网格构成画面；开始屏幕由可自由排列、可动态更新的 Live Tiles（活动磁贴）组成，把电话簿、照片、音乐视频与 Xbox Live 等入口整理成「Hub（集线区）」。微软把这种设计目标概括为「glance and go」，即看一眼就能获得信息，不必逐层点开。发布时由微软 CEO 史蒂夫·鲍尔默与负责该项目的安迪·李斯、乔·贝尔菲奥雷等人介绍，定位是与桌面 Windows 互补的个人设备系统。

硬件规格由微软统一规定：最低 1GHz 高通骁龙处理器、512MB 内存、480×800 分辨率、电容触控、Back / Start / Search 三个实体键、独立拍照键，存储不可由用户扩展，音乐与照片通过 Zune 桌面软件同步。系统首发于 2010 年 10 月 21 日在欧洲上市，11 月 8 日进入美国；首发机型包括 HTC HD7、三星 Omnia 7、LG Optimus 7 与戴尔 Venue Pro，戴尔那台用竖滑全键盘做出了一点形态上的区别。商店在首发时的应用数量约以千计，随后增长，但「应用少」的标签从一开始就贴在它身上。系统把 Xbox Live 游戏、Office 与 Zune 音乐放进了主要入口，用户登录微软账号后能在手机上查看成就与 Gamerscore，这在当时的手机里是新鲜事。

上市初期的 Windows Phone 7 在媒体评测里得到的评价集中在界面新鲜与操作顺畅两点，短板则指向应用数量、复制粘贴这类基础功能，以及企业用户看重的 VPN、可移动存储等特性缺失。微软把系统更新的节奏握在自己手里，本意是保证体验一致，实际效果是每次更新都要等所有机型排期，早期一次更新还引发了部分三星机型无法启动的问题（该更新事故的具体范围与时间待核实）。这些细节叠加起来，让平台在上市第一年没能形成口碑扩散，也让「先等它成熟」成了很多潜在用户的默认态度。

首发版本也没有复制粘贴与第三方多任务，铃声不能自定义，第三方浏览器受限，这些缺口在 2011 年 3 月的「NoDo」更新与 2011 年秋的「Mango」（Windows Phone 7.5）中逐步补齐。Mango 在 2011 年 5 月公布细节，加入了快速应用切换、IE9 移动版、消息会话视图、把社交网络并入 People Hub、Local Scout 与 Bing Vision 等功能，总计宣传为数百项改进。Mango 还改善了邮件与 Office，把默认输入法换成更实用的版本，并允许开发者接入更多系统能力。这一代硬件随后出现 HTC Titan（约 4.7 英寸）等大屏机型，诺基亚的 Lumia 800 与 710 也在这一代进入市场。

真正改变这条产品线走向的是与诺基亚的结盟。2011 年 2 月 11 日，诺基亚 CEO 史蒂芬·埃洛普与微软 CEO 史蒂夫·鲍尔默宣布战略合作，诺基亚把 Windows Phone 定为智能手机主平台，Symbian 转为维护性的「特许经营」平台，MeeGo 收缩为实验项目。此前流出的埃洛普内部备忘录以「燃烧的平台」的比喻描述诺基亚处境，把公司比作站在起火油平台上、只能在跳进冰水与留在火里之间选择的人。这次结盟把 Windows Phone 的应用规模缺口交给诺基亚的渠道与品牌去补，也把诺基亚的命运与微软绑定在了一起。同年 10 月 26 日，首批诺基亚 Windows Phone 机型 Lumia 800 与 Lumia 710 发布，Lumia 800 沿用自 N9（MeeGo）的一体成型聚碳酸酯外壳与 ClearBlack AMOLED 屏，成为这一平台在外观上最有辨识度的产品线；2012 年初的 Lumia 900 面向美国市场，进一步把这条产品线铺开。

### 2.4 Windows Phone 8 的重置与诺基亚收购（2012–2013）

2012 年 6 月 20 日，微软在旧金山举行 Windows Phone Summit，公布 Windows Phone 8。它放弃 Windows CE 内核，改用与 Windows 8 相同的 Windows NT 内核，支持多核处理器、更高分辨率、microSD 扩展、NFC 支付、原生 C++ 与 Direct3D，并引入 Wallet、应用内购买与企业功能。代价是架构不兼容：所有 Windows Phone 7 机型无法升级到 Windows Phone 8，只能停留在 Windows Phone 7.8。微软给出的理由是旧内核无法支撑新硬件与新能力，但这次切换让最早一批用户与开发者付出了迁移成本，也让硬件厂商重新排队，平台在需要积累的阶段又清空了一次。

Windows Phone 8 随 Windows 8 于 2012 年 10 月 29 日上市，代表机型有三星 Ativ S、HTC 8X / 8S 与诺基亚 Lumia 920、Lumia 820。Lumia 920 以光学防抖、无线充电与 PureMotion HD+ 屏作为卖点，是诺基亚在成像上押注的开始。2013 年的 Update 3 补上 1080p 分辨率与大屏支持，并加入四核骁龙 800 的适配，诺基亚据此推出 6 英寸的 Lumia 1520；同年 7 月发布的 Lumia 1020 以 4100 万像素 PureView 传感器与卡尔·蔡司镜头成为手机摄影的话题机型；面向入门市场的 Lumia 520 则成为这条产品线出货量最大的型号之一（具体累计销量待核实）。在诺基亚以外，HTC、三星、华为（Ascend W1 / W2）、中兴等也陆续推出 Windows Phone 机型，国内市场还有海尔、天语等厂商参与（这些国内机型的具体型号与年份待核实），但话语权集中在诺基亚手里，其出货占了平台的大多数。

2012 到 2013 年，智能手机市场已由 iOS 与 Android 分完，Android 阵营在低价段迅速放量，诺基亚同时还在处理 Symbian 的存量与 Asha 低端产品线的过渡。Windows Phone 8 的硬件规格追上主流，但价格段落与渠道覆盖仍不足以支撑规模，Lumia 520 之类的低价机型承担了冲量的任务，旗舰机型则靠相机与外观维持关注度。微软与诺基亚在这两年投入了大量营销与开发者补贴，换来的份额停留在个位数，说明单靠一方让利无法扭转平台选择的惯性。

同一时期，第三方数据普遍显示 Windows Phone 的全球智能手机系统份额在 2013 年前后达到峰值，大致在 3% 到 4% 的区间，美国市场约在 3% 附近，个别欧洲市场的占比更高（确切峰值与各国数字待核实）。诺基亚的努力把平台从「几乎不存在」抬到了「看得见的第三名」，但距离能自我维持的应用生态仍有明显距离：开发者看到的装机量不到 iOS 与 Android 的一个零头，主流应用的上架与更新因此一再推迟。2013 年 9 月 3 日，微软宣布以约 72 亿美元收购诺基亚的设备与服务业务并授权其专利，其中包括诺基亚的 Lumia 与 Asha 品牌、位于芬兰与全球的设备团队；交易于 2014 年 4 月 25 日完成，诺基亚的设备部门随后以「微软移动（Microsoft Mobile）」的名义运作。

### 2.5 收购之后：Windows Phone 8.1 与战略转向（2014–2015）

2014 年 2 月，萨提亚·纳德拉接任微软 CEO。同年 4 月 2 日的 Build 大会上，Windows Phone 8.1 发布，带来语音助手 Cortana（中文名「小娜」）、下拉通知中心 Action Center、可更换的开始屏幕背景与磁贴样式、滑动输入法、IE11，以及把手机与 PC 代码共享的「通用 Windows 应用」雏形；微软同时宣布对 9 英寸以下设备免除 Windows 授权费，试图压低整机成本，让厂商愿意做更便宜的手机。首批搭载 8.1 的机型包括 Lumia 630 / 635，随后是 Lumia 930 / Icon，以及面向新兴市场的低价机型。Cortana 以《光环》系列中的角色命名，中文版「小娜」在功能与语音上做了本地化，成为这一代少有的被广泛讨论的新能力。

诺基亚的设备业务并入微软后，Lumia 品牌保留，但产品节奏开始受微软整体战略牵制。诺基亚在被收购前推出的 Android 机型 Nokia X 系列在 2014 年 7 月被微软停止，此前诺基亚还曾用 Asha 平台覆盖低价市场，这些低端业务在微软手里被逐步收缩。2014 年 3 月，微软把 Office 带到 iPad，跨平台策略开始压过「先喂饱自家平台」的做法；此后 Office、Outlook、Skype 等微软应用陆续在 iOS 与 Android 上提供完整版本。2015 年 7 月 8 日，微软宣布与手机硬件相关的约 76 亿美元资产减值，并裁减约 7800 个岗位，诺基亚收购案的账目损失由此公开化，公司承认手机业务的定位需要重新考虑。此后微软自己的手机产品线逐步收缩，2016 年 2 月发布的 Lumia 650 成为最后几款 Lumia 之一，微软也不再为消费者市场推出新的 Windows 手机旗舰。

### 2.6 Windows 10 Mobile：Continuum 与终局（2015–2019）

2015 年 10 月 6 日，微软发布 Lumia 950 与 Lumia 950 XL，以及配套的 Microsoft Display Dock，正式推出 Windows 10 Mobile 与手机上的 Continuum 功能：手机通过扩展坞接上显示器与键鼠后，可以运行通用 Windows 应用，呈现接近桌面的多窗口界面，但只支持 UWP 应用，不能运行传统的 Win32 桌面程序。Windows 10 的通用 Windows 平台（UWP）让同一款应用面向 PC、平板、手机、Xbox 与 HoloLens，商店也在 Windows 10 上统一。为吸引应用，微软同时推进几个移植方案：Project Astoria 面向 Android 应用，Project Islandwood 面向 iOS（Objective-C），Project Centennial（桌面桥）面向 Win32，Project Westminster 面向网页应用。其中 Astoria 在 2016 年 2 月被终止，微软表示会把精力转向 iOS 方向；Islandwood 于 2015 年 8 月开源但采用者有限；Centennial 在 PC 上得到实际使用，帮助 Win32 程序进入商店。移植桥的成效不均，说明问题不在工具而在需求。

Windows 10 Mobile 面向既有 Windows Phone 8.1 机型的升级自 2016 年 3 月起分批推送，仅覆盖部分机型，较早的 512MB 内存设备大多被排除（具体起始日期与机型名单待核实）。此后微软几乎没有推出面向消费者的新旗舰，2016 年的惠普 Elite x3（配 Lap Dock，面向企业）与阿尔卡特 Idol 4S 属于少数搭载该系统的后期设备，前者把 Continuum 当作企业移动办公的方案来卖。2016 年 5 月，微软把功能手机业务出售给 HMD Global 与富士康旗下的 FIH Mobile，诺基亚品牌由此进入授权生产阶段，并在 2017 年以 Android 手机的形式回归。2017 年 10 月，微软高管乔·贝尔菲奥雷在社交平台上确认系统不会再有新功能与新硬件，平台转入维护状态，他同时提到应用缺口与开发者不愿投入是主要原因。

Windows 10 Mobile 的最后一个版本为 1709（Fall Creators Update，2017 年 10 月），支持于 2019 年 12 月 10 日终止，微软建议用户转向 iOS 或 Android，并说明此后不再提供安全更新与技术支持。部分配套服务在随后几年陆续结束（例如 Office 等应用在移动版上的支持截止时间待核实）。2020 年面世的 Surface Duo 双屏设备运行 Android，微软把它定位为「装在口袋里的 Surface」而非 Windows 手机，标记了微软自有移动操作系统的收场：公司继续做移动端软件与游戏服务，但不再自己维护一套手机系统。

## 4. 技术与硬件

Windows CE 的内核血统在这段历史里被切割过两次。1996 年到 2012 年，从 CE 1.0 到 Windows Phone 7，用的是微软为嵌入式设备设计的 CE 内核；2012 年的 Windows Phone 8 换成与桌面 Windows 8 同源的 NT 内核；2015 年的 Windows 10 Mobile 继续沿用 NT 内核并接入 UWP。内核切换带来能力与兼容性的取舍：CE 内核让早期设备能以较小的资源运行，也把平台锁在多处理器体系与厂商定制中；NT 内核让手机具备多核、更高分辨率与原生代码能力，代价是「Windows Phone 7 机型不能升级到 Windows Phone 8」这一硬性断裂，以及开发者的代码需要重写。对一个需要用连续几代硬件积累用户的产品线来说，中途换内核等于把已有的装机量归零重来。

Windows Mobile 时代的硬件差异来自授权模式。处理器有 ARM、Intel XScale、三星、德州仪器等多个来源，屏幕从 QVGA（240×320）到 WVGA（480×800）不等，输入方式以太尺寸电阻屏加触控笔为主，部分机型保留全键盘或滑盖键盘。HTC 是这一模式最大的受益者与实际主导者，既做自有品牌，也替运营商和其他品牌代工，多普达即其在中国大陆的品牌。厂商在同一套系统上叠加自制今日界面，形成了「同一系统、不同体验」的格局；这在应用商店尚未普及的年代是卖点，在电容触屏与统一体验成为标准之后就变成了负担，用户难以判断「这台机器到底好不好用」。2009 年的 HTC HD2 把这条路线推到顶点：4.3 英寸电容屏、1GHz 高通骁龙、448MB 内存（具体配置待核实）、运行 Windows Mobile 6.5，社区还让它能启动 Android 与 Windows Phone。

Windows Phone 7 反过来把硬件规格收到微软手里。最低 1GHz 骁龙、512MB 内存、480×800 分辨率、三个实体键、独立拍照键，图形处理由 Adreno 200 级别的 GPU 承担，存储不可扩展。统一规格带来的是稳定的流畅度，也带来厂商难以在外形与参数上做出差异的问题：处理器只来自高通一家，外观与界面都被平台框住，硬件厂商能玩的只有机身材料、摄像头与屏幕。戴尔 Venue Pro 用竖滑全键盘做出过一点区别，诺基亚进场后把差异押在材料与相机上。Lumia 800 借自 N9 的一体成型聚碳酸酯外壳与弧面屏成为这一平台上最好辨认的工业设计，后续的 Lumia 920 加了光学防抖与无线充电，Lumia 1020 把 4100 万像素的 PureView 传感器与卡尔·蔡司镜头塞进机身，Lumia 1520 用 6 英寸屏幕进入大屏市场，Lumia 520 则用低价把平台铺到入门市场。

Windows Phone 8 之后，硬件限制放开，多核、720p 与 1080p、microSD、NFC 陆续进来，原生 C++ 与 Direct3D 让移植游戏更现实。但平台的处理器来源仍集中在高通，旗舰机的绝对性能在同代 Android 阵营面前不占优势，屏幕与电池等参数也不常领先。到 Windows 10 Mobile，Continuum 成为这套硬件与系统的核心卖点：手机通过 Microsoft Display Dock 接显示器与键鼠，运行 UWP 应用并呈现桌面式界面，惠普 Elite x3 配上 Lap Dock 把它包装成企业设备。这条路径的限制写在同一份规格里——只支持 UWP，不支持传统 Win32 桌面程序，因此无法从 Windows 庞大的桌面软件库里借力。手机与电脑共享同一套系统，并没有让手机继承电脑的软件规模，这是后来被反复讨论的一点。

成像技术是这段历史里少数由硬件主导的差异点。诺基亚把 PureView 的命名体系从 Symbian 时期的 808 PureView 延续到 Lumia 系列，用大尺寸传感器配合像素合并与光学防抖，在低照度下把多个像素合成一个大像素，再用过采样输出较小尺寸的照片，这套思路后来被手机行业普遍采用。Lumia 1020 的 4100 万像素传感器是这一路线的极端形态，代价是拍摄与存储的等待时间，以及机身厚度上的妥协。Continuum 的另一半在软件：手机接上显示器后进入桌面式界面，系统需要判断哪些应用以窗口形式运行、哪些以全屏运行，这套判断依赖应用是否按 UWP 规范适配；没有适配的应用在扩展屏上表现受限，这也是它难以真正替代电脑的原因。

技术参数在这段历史里很少直接决定结局。Windows Phone 7 在同期手机中操作流畅度口碑不错，统一规格也减少了碎片化；Windows Mobile 6.5 的功能完整度在 2009 年并不落后；Lumia 1020 的传感器规格到 2013 年仍是话题中心。决定份额的仍是应用供给、开发者回报与用户规模组成的循环，硬件只能决定一台机器能不能卖出去，不能决定一个平台能不能活下来。这一点在后文展开。

## 5. 软件生态与平台气质

Metro 是这段历史里传播最广的软件资产。它由 Zune 团队与 Windows Media Center 的界面经验汇合而成，诺基亚合作期间的微软设计负责人是阿尔伯特·沈，乔·贝尔菲奥雷长期主持 Windows Phone 的产品方向。Metro 的原则是去拟物、重排版与留白、把内容放在界面结构之前，用 Segoe 字体、色块与运动来组织信息。它与同期 iOS 的拟物化、Android 早期的深色工具风都不相同，因而辨识度很高；界面里没有阴影、渐变与仿皮革纹理，信息本身占据画面。「Metro」这个名字在 2012 年 8 月被微软要求停用，据公开报道与德国零售商 Metro AG 的商标争议有关，此后改称「Modern UI」或「Windows 8 风格界面」，设计原则本身没有改变。

Live Tiles 是 Metro 在手机上的具体形态。开始屏幕由方格构成，每个方格可以翻转显示天气、未读消息、照片或应用动态；用户可自由调整大小与位置，把最常看的信息放在最顺手的地方。微软把这种设计概括为「glance and go」：先在开始屏幕获得状态，再决定是否进入应用。以 People Hub 为中心的社交聚合把通讯录、社交动态与消息放进同一处，是当时的差异化设计，也在应用各自为政的后来成了包袱——当用户习惯了某个社交应用自己的信息流，系统级聚合反而显得多余。开始屏幕右侧的应用列表按字母排列，取代了此前的多页图标网格，这一套排列逻辑后来在 Windows 8 上与桌面磁贴合并。

Xbox Live 的接入让手机第一次成体系地承接了游戏机上的账户体系。Windows Phone 7 起，手机上有独立的游戏集线区，登录 Xbox Live 账号后可以查看好友、查看成就与 Gamerscore，玩到带成就的移动游戏；首发与随后一段时间里出现了包括益智类与合作类在内的多款 Xbox Live 作品（首发阵容的具体名单待核实）。这套身份延续到后来微软在 Android 与 iOS 上的 Xbox 应用，也为云端游戏时代的跨设备账户打了底：游戏存档、成就与好友关系跟着账号走，而不跟着某一台机器走。办公一侧，Office Hub 与 OneNote 让手机能打开并编辑桌面格式的文档，配合 Exchange 与 SharePoint 面向企业用户，这是诺基亚与微软都看重的一块。

内容与服务一侧继承的是 Zune 血统。Zune 是微软在 2006 年推出的音乐播放器品牌，2009 年的 Zune HD 已经在用后来被称为 Metro 的界面；Windows Phone 7 的音乐、视频、照片同步都通过 Zune 桌面软件完成，订阅服务为 Zune Music Pass。Zune 硬件在 2012 年前后退出，品牌并入 Xbox Music（后为 Groove），但它的界面遗产与「以内容和订阅为中心」的思路留在了 Windows Phone 上。商店则从 Windows Phone Marketplace 起步，随系统更名与合并，最后成为 Windows 10 统一的 Microsoft Store。商店的应用数量长期落后：首发时只有千余款，到 2013 年前后才达到十万量级，与 iOS、Android 的百万级条目不在同一量级（各时间点的具体数字待核实）。

开发者工具链在这段历史里换过三次：Windows Phone 7 用 Silverlight 与 XNA，Windows Phone 8 转向 WinRT 与 C#/C++，Windows 10 Mobile 统一到 UWP。每次切换都让已有的代码与经验需要重做，XNA 的停更是很多独立开发者的转折点——在小平台上做游戏本就依赖这套易上手的技术栈，工具消失意味着之前的投入难以延续。微软为填应用缺口做过大量补贴与移植支持，包括提供免费的开发工具、资助应用上架、以及前述的 Project Astoria、Islandwood、Centennial 三条移植桥，但这些投入没有形成自发的开发者回报循环：补贴能买来「有」，买不来「一直在更新」。

应用缺口是这段历史最常被引用的解释。Instagram 在 2013 年 11 月才以 Beta 形式登陆 Windows Phone，距其 iOS 版发布约三年；Snapchat 始终没有官方版本，用户只能用第三方客户端；YouTube 由谷歌运营，双方在 2013 年就客户端问题发生公开争执，微软自制的应用被要求下架，最后只能做网页封装。银行、打车、智能家居等生活类应用的缺席更直接地影响日常选择，很多应用只有第三方开发者做的非官方版本，功能与安全都无法保证。中文应用的情况类似：微信有 Windows Phone 版本，但功能相对基础且很晚才更新甚至停止维护；淘宝、支付宝等主流应用长期缺席或仅有残缺版本（具体版本时间线待核实）。商店里搜不到需要的东西，成为很多用户离开的直接原因。

平台气质上，Windows Phone 带有微软式的规范与控制：系统更新由微软统一推送，而不像 Windows Mobile 那样交给厂商与运营商，这一点在早期被视为优点，避免了 Android 式的版本碎片，在需要灵活适配不同市场时又成为限制。它同时混合了商务、音乐与游戏三种气质——Office 与 Exchange 面向办公，Zune 与音乐服务面向消费，Xbox Live 面向游戏。这种混合让它难以用一个词向普通消费者说明自己是什么，而 iPhone 与 Android 各自都有清晰的位置：一边是「最好用的手机」，一边是「什么都能装的手机」。品牌与营销上，微软曾在 2012 年前后做过「Smoked by Windows Phone」的现场对比活动，用速度挑战来证明体验，但营销无法替代应用供给。

## 6. 为什么它重要 / 为什么它输了

它的重要性首先在于界面语言。Metro 与 Live Tiles 把扁平化、排版驱动、以信息块代替图标的做法带到了大众面前，这套语汇随后进入 Windows 8 与 Windows 10，并成为 2010 年代扁平化潮流中的一支。苹果在 2013 年的 iOS 7 转向扁平设计，与 Windows Phone 之间是否存在直接因果，属于评价范畴，公开资料里没有一致结论，这里不做断言。可以确认的是，Windows Phone 在 2010 年就把动态磁贴式的「一眼看信息」的开始屏幕做成了系统默认，这比后来各家陆续加入的桌面小组件与信息卡片早了多年；用动态内容代替静态图标，此后成为移动界面设计的常规手段。

第二在于跨设备与跨形态的应用构想。UWP 让同一份应用面向手机、PC、平板、Xbox 与 HoloLens，Continuum 让手机接上显示器就用出桌面式界面，手机上的 Xbox Live 成就让游戏账户跨设备延续。这些想法在 2015 年前后由微软集中提出，其中一部分后来以别的形式实现：三星在 2017 年推出的 Samsung DeX 走的是同一类桌面模式路线，云端游戏让 Xbox 账户真正跨到了手机屏幕上。微软自己的 UWP 与统一商店也在 PC 上留下了实际影响，Windows 10 之后系统自带应用的更新与分发都走这条通道。手机与桌面共享应用库的目标没有在当时实现，但方向被保留了下来。

第三在于产业案例价值。微软 2013 年以约 72 亿美元收购诺基亚设备业务、2015 年为此计提约 76 亿美元减值并裁减约 7800 个岗位，规模足以说明押注手机硬件的代价。Windows Phone 与更早的 Windows Mobile 一起，成为「第三种生态」在双头垄断市场里难以立足的标准案例，被反复用于讨论网络效应、开发者回报与平台启动门槛。它也是硬件收购整合的教材：把一家以硬件与渠道见长的公司并入一家以软件与授权见长的公司，两年后以减值与裁员收场，说明平台与硬件的协同需要的不只是资金。

从第三方机构多年的统计看，全球智能手机系统份额在 2010 年代中期之后长期由 Android 与 iOS 两方分割，两者合计接近全部市场，Windows Phone 的最好成绩也没有超过一成，多数时间在个位数低位，随后跌破百分之一（各年度具体数字待核实）。这组分布说明智能手机是赢者通吃的市场，规模会自我强化：更大的装机量吸引更多开发者，更多应用吸引更多用户，第三名的处境会随时间变差而不是变好。Windows Phone 的每一次投入都在与这条曲线对抗，诺基亚的销量、微软的资金与移植工具能减慢下滑，无法改变方向。

失败的原因可以拆成几条互相关联的事实。

进入太晚。iPhone 2007 年发布、App Store 2008 年上线，Android 2008 年随 HTC Dream 与 Android Market 出现，Windows Phone 7 到 2010 年 10 月才上市，晚了大约三年。它面对的已经不是「有没有智能手机」的市场，而是两个已有大量应用、开发者与用户的成熟平台。应用商店是典型的双边市场，用户与应用互相吸引，先发者积累的规模会把后来者挡在门外，Windows Phone 没有在应用数量或开发者收入上打开缺口；诺基亚的渠道最多能把硬件卖出去，不能凭渠道凭空造出应用供给。

平台重置损伤了信任。Windows Phone 7 到 Windows Phone 8 换成 NT 内核，老机型无法升级，只能停在 7.8；Windows 10 Mobile 对 Windows Phone 8.1 机型的升级也只覆盖部分设备，早期 512MB 机型被排除在外。两次断裂都发生在平台需要积累用户的阶段，早期用户与开发者在一次换机周期里发现自己投入的应用与经验贬值，硬件厂商也要重新适配，这削弱了本就不多的长期承诺。老用户的口碑传播是平台增长的重要来源，连续重置等于主动放弃这条通道。

开发者回报不足形成自我强化。用户规模小，付费意愿与广告价值有限，为 Windows Phone 单独开发与维护应用的成本难以收回，主流开发者因此压低优先级，把资源留给 iOS 与 Android；应用缺口又阻碍新用户进入，循环就此固定。微软的补贴与移植工具缓解了部分问题，但没有改变开发者的收入预期，Project Astoria 在 2016 年终止即是这种努力未能转化为生态的信号。对开发者而言，理性选择是把有限人力投到回报更高的平台，这与微软的技术能力无关。

微软自身的战略在摇摆。Windows Mobile 到了 2010 年才做消费级重启，此前已有 Kin 的失败；诺基亚被拉进来之后，平台又与微软内部「一个 Windows」的整合目标纠缠，WP8 的重置与 W10M 的分支都反映了这一点。纳德拉在 2014 年接任后推行跨平台策略，微软开始把 Office、Outlook 等应用率先放在 iOS 与 Android 上，把公司重心从「移动优先」调整为「云端与跨平台」。当自家最好的应用在对手平台上体验更好时，Windows Phone 作为载体的必要性进一步下降，公司内部也缺少为这个平台持续投入的理由。

运营商与硬件生态没有提供足够支撑。美国市场上运营商话语权大，iPhone 与 Android 占据货架与补贴资源，部分运营商对第三平台的引进持观望态度（具体案例待核实）；三星、HTC、LG 等厂商做 Windows Phone 更多是分散风险的占位，主资源仍在 Android；平台还限定处理器来自高通一家，厂商难以区分产品。诺基亚凭借渠道与品牌撑起了大半年出货，被微软收购后，这块力量被并入一家对手机硬件信心已经动摇的公司，新机节奏与营销投入都随之收缩。

技术优势没有换成市场。Windows Phone 7 的流畅、Lumia 的相机、Continuum 的概念都得到过讨论，但这些都发生在应用与开发者这一层之外。平台战争最后回到应用供给、开发者回报与用户规模的正循环，Windows Phone 来得太晚，也没能在这个循环里转起来。这段历史里最容易被忽略的一点是：微软几乎把「系统做得好」这件事做到了，问题出在系统之外。

## 7. 它留下了什么

设计语汇的遗留最直接。Metro / Modern UI 的扁平化、排版驱动与色块组织进入了 Windows 8 与 Windows 10，微软在 2017 年提出的 Fluent Design 也能看到这一路线的延续。Live Tiles 的动态信息块与「一眼看信息」的目标，与后来各家系统的桌面小组件、信息卡片属于同一种思路；今天的手机开始屏幕默认提供可翻转的信息块，其源头之一可以追溯到 2010 年这块方格屏幕。Metro 还改变了微软自己的产品面貌：Windows 8 的开始屏幕、Office 的界面调整、Xbox 主机的仪表盘设计，都带着这套语言的痕迹。

产品思路的遗留同样清晰。Continuum 的「手机接显示器当桌面用」在三星 DeX 上以更成熟的形式出现，后来 Android 阵营的桌面模式与折叠屏多任务都能看到相近的问题设定；UWP 的统一应用模型让微软商店在 PC 上继续存在，Windows 10 之后的系统应用分发都基于这条通道；手机上带成就的 Xbox 账户体系延续为跨平台的 Xbox 应用与云端游戏服务，微软的游戏业务今天在 Android 与 iOS 上都有覆盖。诺基亚 Lumia 的成像路线——大尺寸传感器、像素合并、光学防抖、与镜头厂商合作——在 2013 年就被 4100 万像素的 Lumia 1020 摆到台面上，成为后来手机摄影硬件竞赛的先例之一，也让「像素数量之外还有传感器与算法」这件事被更多普通用户知道。

产业层面的遗留是「平台战争失败」这份样本。Windows Phone 与 Windows Mobile 提供了关于进入时机、双边市场、平台重置成本、以及硬件收购整合难度的完整材料，其中诺基亚收购案的减值与裁员数字使其成为商学院与业界复盘的常见案例。微软自身则在这段失败之后转向服务与跨平台：Office、Outlook、Xbox 等服务成为公司在手机上的实际存在方式，2020 年的 Surface Duo 直接运行 Android。自有移动操作系统的故事到此结束，微软移动端的故事换了形式继续，公司在手机上的存在从「系统提供者」转成了「应用与服务提供者」。

### 7.1 中国玩家的 Windows Phone 记忆

在中文语境里，这条产品线被记住的方式分成前后两段。前一段是 Windows Mobile 时代的商务与折腾记忆：多普达与 HTC 的中高端机型在水货渠道流通，掌上电脑与智能手机论坛（如 TOMPDA 一类）里全是 CAB 安装包、今日界面美化与刷机教程，用户用它炒股（同花顺、大智慧一类）、导航（凯立德、道道通一类）、处理 Office 文件、上 QQ 与飞信。那个年代微信还没成为主线，装软件靠论坛与下载站，电池与触控笔是随身配件，这种「自己动手装系统、自己找应用」的经验，构成了很多中国用户对 Windows 手机的第一印象。同一时期诺基亚与 Symbian 占据大众市场，Windows Mobile 守的是「公司配的高端机」这个位置。

后一段是诺基亚 Lumia 与 Windows Phone 时代。诺基亚在中国有深厚的品牌基础，Lumia 800、Lumia 920、Lumia 1020 等机型以一体成型外壳与相机为卖点进入国行市场，也通过运营商渠道销售（例如面向中国移动网络制式的定制版本，具体型号待核实）。微软的语音助手在中国以「小娜」为名上线，是少数做了本地化并留下印象的功能。用户的普遍体验是：系统界面与流畅度得到认可，相机表现有话题，但商店里的中文应用缺口很快显现——常用应用要么没有，要么是功能残缺的版本，社交与支付类应用长期不到位（具体应用的版本与停止维护时间待核实）。对很多中国用户来说，Lumia 是「好看、好拍、但不够好用」的一台手机，最终换回了 Android 或 iPhone；这种「因为一个功能买它、因为一堆功能离开它」的路径，在中文社区的讨论里出现得很频繁。

这条产品线在中国的退场也有一串节点：功能手机业务在 2016 年出售给 HMD Global 后，诺基亚品牌以 Android 手机的形式回归；微软此后的设备不再以 Windows 手机为主，国内渠道也随之清空库存。对国内玩家而言，Windows Phone 更多与「诺基亚最后的旗舰」和「商店里搜不到应用」这两句话绑定在一起，而不是与某个爆款软件或某段联网热潮绑定；它留下的倒是一些具体的画面——4100 万像素样张里放大后仍在的青砖纹理、开始屏幕上自己排布的一列磁贴、以及那个最终没能用起来的支付入口。

## 8. 一句话总结

Windows Phone 把 Metro 与 Live Tiles 的界面语言、手机上成体系的 Xbox 成就、诺基亚 Lumia 的工业设计与成像、以及 UWP 与 Continuum 的跨设备构想留给了设计史与生态史，却在应用供给、开发者回报与用户规模的正循环上迟到太久，最终以一个自有移动平台的代价，换来微软向跨平台服务的转身。
